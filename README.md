# Deen音乐下载器

基于 Flask 的多平台音乐下载器，内置网易云音乐、QQ 音乐与酷狗音乐完整支持。多账号管理、定时同步歌单、断点续传下载、元数据写入（封面/歌词/专辑）、音乐库整理、Web 界面管理，并支持飞牛 fnOS 一键安装。

> 技术架构、目录结构、数据模型、API 接口等开发细节见 [docs/技术文档.md](docs/技术文档.md)。

## 关于本 Fork

本仓库是 [chongya369/music-downloader](https://github.com/chongya369/music-downloader) 的个人 fork（[nonewind/music-downloader](https://github.com/nonewind/music-downloader)），自 **v0.7.6.5** 起与上游产生方向性偏差，独立演进维护。

**Fork 的目标**：

- **下载治理优先**：下载产物安全（不误删/不误覆盖已有文件）、数据库记录与磁盘文件一致（历史标记成功但文件已丢失时，重新发起下载自动放行而不是被"已下载"拦截）、路径超长截断保护文件名中的歌曲 ID——详见 [更新日志](docs/CHANGELOG.md) v0.7.6.5 起的条目
- **下载文件去重**（0.8.1.0 / 0.9.0.0）：「音乐库 → 待处理」后台扫描下载目录，按平台隔离识别同曲多版本与字节级重复文件，推荐保留高规格版本，清理一律移入回收站并同步修正歌曲指向；下载完成时还会按声音内容比对，与库里已有文件完全相同的新下载直接撤回
- **音乐库**：按「歌手 → 专辑 → 歌曲」浏览下载目录（按文件夹分，不按标签分），在专辑里做简单整理：改专辑名/专辑歌手/年份（文件夹可跟着改名）、把歌移到别的专辑、删歌进回收站、清理空文件夹、处理不在「歌手/专辑」结构里的文件。所有改动先预览、再执行，不覆盖任何已有文件，下载记录里的文件位置一起更新。不做通用文件浏览/编辑
- **音质升级闭环**（0.8.2.0）：下载页「音质升级」列出音质低于当前设置的已下载歌曲，批量重下更高音质；只有取到严格更高的档位才下载（同档不白耗额度），取不到时自动换账号、仍不行则跳过并冷却 7 天；升级为不同格式后旧文件保留，交由「音乐库 → 待处理」去重清理；全程沿用降级保护
- **免登录与访问控制**（0.9.0.0 / 0.9.1.0）：单用户自用，去掉登录；新装默认只监听本机，可选访问令牌，敏感操作只对可信来源开放，见下方「访问控制与安全」
- **为常用操作重做的界面**（0.10.0.0）：页面并成 找歌 / 下载 / 音乐库 / 设置 四个，电脑和手机都好用
- **测试与守护**：pytest 测试设施与回归测试，改动先测后修，不为局部问题引入复杂架构
- **面向 fnOS 部署的个人自用优化**

**与上游的关系**：持续跟进上游更新；通用性修复仍尽量以 PR 回馈上游（如已合并的 #7 同名歌曲冲突修复）。本仓库的治理方向与界面调整暂不向上游提 PR，仅在 fork 内演进。

## 功能特性

- **三平台支持**：网易云 / QQ 音乐 / 酷狗音乐账号管理、歌单同步与下载（三平台均支持扫码登录）
- **多账号调度**：接力 / 轮询两种模式，VIP 偏好过滤，单账号月额度 + 每小时限额管控；QQ 账号登录凭证定时自动刷新，减少提前失效
- **音质控制**：三平台独立音质设置，档位覆盖普通档与会员高阶档（QQ 臻品母带/OGG 640k，网易云超清母带/杜比全景声/沉浸环绕声等），目标音质取不到流时按平台沿降档链回退：

  - **网易云**：`jymaster → hires → lossless → exhigh → higher → standard`（`higher` 为旧档，仅降级链内保留、界面不暴露）；`jyeffect` / `dolby` / `vivid` / `sky` 四档**不进降级链**，无对应权益时直接失败提示，不静默降档
  - **QQ 音乐**：`jymaster → hires → exhigh → standard`（`hires` 与 `lossless` 同为 FLAC、`exhigh` 与 `higher` 同为 320k，链内已去重）；`ogg640` 不进链，由客户端内部降 128 兜底
  - **酷狗音乐**：**外层不降档**（档位在客户端内部降级；匿名状态下服务端强制封顶 128kbps）
- **定时同步**：多时间点 cron 触发 + 随机抖动延迟，歌单更新自动下载新歌
- **下载增强**：断点续传、失败重试、MP3/FLAC/OGG 元数据与封面歌词写入、路径长度保护；目录结构默认 `歌手/专辑 (年份)/歌名-歌曲ID`
- **任务控制**：下载任务可逐个暂停 / 继续 / 删除，也可一键暂停全部 / 继续全部；暂停保留断点文件、继续时断点续传，删除立即中止并清理临时文件
- **找歌**：搜索歌曲/专辑、官方排行榜、热门歌单，单曲/专辑批量下载；每首歌右侧直接显示下载状态和进度
- **下载条**：有任务在下载时，每个页面底部显示当前歌曲、进度、排队数和失败数
- **API 服务内置**：三平台 API 二进制随仓库内置，启动即自动拉起，无需外部搭建
- **部署灵活**：Windows / Linux 源码运行或单文件可执行程序、Docker、飞牛 fnOS 应用中心一键安装（统一网关接入）
- **音质升级**：已下载歌曲批量升级到当前音质设置，取不到更高音质自动跳过，不覆盖、不浪费额度
- **音乐库**：按歌手、专辑浏览和整理下载目录；重复文件识别与清理（一律进回收站），扫描与清理均为后台任务，刷新页面不丢进度
- **Web 管理**：下载记录、失败重试、账号 JSON 导入导出，打开即用（无登录）

## 页面一览

| 页面 | 做什么 |

## 安装与运行

### 方式一：飞牛 fnOS（推荐 NAS 用户）

1. 从 [Releases](https://github.com/nonewind/music-downloader/releases) 下载 `deen-music-downloader-<版本号>.fpk`
2. fnOS「应用中心 → 手动安装」上传 fpk 文件
3. 安装完成后从桌面或应用列表打开，经统一网关（`/app/deen-music-downloader`）访问

数据库与下载目录自动落在 fnOS 持久化数据卷，升级覆盖安装数据不丢失。

### 方式二：Release 可执行文件

1. 从 [Releases](https://github.com/nonewind/music-downloader/releases) 下载对应平台 zip（`deen-music-downloader-<版本号>-win-x64.zip` / `deen-music-downloader-<版本号>-linux-x64.zip`）并解压
2. Windows 双击 `deen-music-downloader.exe`；Linux 执行 `./deen-music-downloader`
3. 浏览器访问 `http://localhost:45600`

产物已内置当前平台 API 二进制，无需任何手动配置。

### 方式三：Docker

见 [README.Docker.md](README.Docker.md)。容器里的服务对宿主机所在网络开放，**请务必设置访问令牌**或只映射到本机端口。

### 方式四：源码运行

**Windows：** 双击 `run_web.bat`（自动创建虚拟环境、安装依赖、启动服务）

**Linux：**

```bash
chmod +x run_web.sh
./run_web.sh
```

手动方式（两平台通用）：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt    # Windows 为 .venv\Scripts\python.exe
.venv/bin/python webapp/app.py
```

> **macOS 说明**：内置 API 二进制仅提供 Windows / Linux x64 版本，macOS 需自行部署各平台 API 服务并在「设置 → 常规 → 高级：API 服务」里填写自定义 API 服务地址。

## 快速上手

1. **打开应用**：浏览器打开 `http://localhost:45600`（fnOS 经统一网关打开），无需登录直接使用
2. **添加账号**：「设置 → 账号」点「添加账号」，可直接扫码登录（三平台均支持，QQ 同时支持微信扫码），或粘贴浏览器 Cookie（网易云须含 `MUSIC_U`，QQ 须含 `uin` 或 `musicid`，酷狗须含 `token`）
3. **下载歌曲**：在「找歌」页搜索歌曲或专辑，点右侧下载；进度在搜索结果和页面底部的下载条上都能看到
4. **关注歌单**（可选）：「找歌 → 我的歌单」点「用链接添加」，粘贴歌单链接或 ID，之后按设置的同步时间自动下载新歌
5. **处理失败**：「下载」页的「下载记录」里可以看失败原因、单首重试或全部重试

图文详细步骤见 [初次使用教程](docs/初次使用教程.md)（含各平台 Cookie 获取方法）。

| `use_custom_api_url` | `false` | 是否使用自定义 API 服务 URL（勾选时内置服务禁用） |
| `custom_api_url` | （空） | 自定义 API 服务 URL，`use_custom_api_url` 为 `true` 时生效 |
| `qq_api_port` | `45602` | QQ 音乐 API 服务端口（0 表示随机空闲端口；修改后需重启程序生效） |
| `use_custom_qq_api_url` | `false` | 是否使用自定义 QQ 音乐 API 服务 URL（勾选时内置服务禁用） |
| `qq_api_base_url` | `http://127.0.0.1:45602` | 自定义 QQ 音乐 API 服务 URL，`use_custom_qq_api_url` 为 `true` 时生效 |
| `kugou_api_port` | `45603` | 酷狗音乐 API 服务端口（0 表示随机空闲端口；修改后需重启程序生效） |
| `use_custom_kugou_api_url` | `false` | 是否使用自定义酷狗音乐 API 服务 URL（勾选时内置服务禁用） |
| `kugou_api_base_url` | `http://127.0.0.1:45603` | 自定义酷狗音乐 API 服务 URL，`use_custom_kugou_api_url` 为 `true` 时生效 |
| `web_port` | `127.0.0.1:45600` | Web 服务监听地址（`host:port` 格式，如 `127.0.0.1:45600`（仅本机）或 `*:45600`（所有网卡），修改后需重启服务）。新装默认仅本机；从旧版本升级的数据库保留原值（旧默认 `*:45600` 即所有网卡），见下方「访问控制与安全」。环境变量 `WEB_PORT` 可临时覆盖（不写库） |

| `level_netease` | （空） | 网易云音质（高→低）：sky / jymaster / vivid / dolby / jyeffect / hires / lossless / exhigh / standard（空=未单独设置，回退旧全局 `level`，其缺省为 exhigh） |
| `level_qq` | （空） | QQ 音乐音质（高→低）：jymaster / hires / lossless / ogg640 / exhigh / standard（空=未单独设置，回退旧全局 `level`，其缺省为 exhigh） |
| `level_kugou` | （空） | 酷狗音乐音质（高→低）：hires / lossless / exhigh / standard（空=未单独设置，回退旧全局 `level`，其缺省为 exhigh） |

| `write_metadata` | `true` | 是否写入元数据（标题/艺术家/专辑/封面） |
| `write_lyric` | `true` | 是否下载并写入歌词 |
| `auto_sync_enabled` | `true` | 是否启用定时同步 |
| `sync_times` | `03:00,09:00,21:00` | 定时同步时间点（HH:MM 逗号分隔） |
| `sync_jitter` | `600` | 同步抖动延迟（秒，0~N 随机延迟，避免固定时刻请求） |
| `max_retries` | `3` | 下载失败最大重试次数 |
| `default_playlist_limit` | `50` | 添加歌单时的默认下载数量 |
| `download_mode` | `fallback` | 多账号下载模式：fallback（接力）/ round_robin（轮询） |
| `prefer_non_vip` | `false` | 是否优先使用非 VIP 账号下载（仅 VIP 歌曲才用 VIP 账号） |

## 数据库位置

数据库为 SQLite 文件（固定文件名 `downloads.db`），位置按以下优先级确定：

| 优先级 | 方式 | 数据库位置 |
|--------|------|-----------|
| 1 | 启动参数 `--data-dir <目录>` | `<目录>/downloads.db` |
| 2 | 环境变量 `APP_DATA_DIR` | `$APP_DATA_DIR/downloads.db` |
| 3 | 缺省 | 打包运行：exe 同目录；源码运行：项目根目录 |

- 目录不存在会自动创建（支持多级）；相对路径按当前工作目录解析，支持 `~`
- `--data-dir` 与 `APP_DATA_DIR` 同时设置时，启动参数优先
- **旧库自动迁移**：指定的数据位置生效、且程序目录存在旧 `downloads.db` 时，首次启动会把旧库**搬走**（不是复制，含 SQLite `-journal/-wal/-shm` 附属文件）；目标位置已有数据库时不会覆盖
- 启动日志会输出实际数据库路径（`数据库文件: ...`）

示例：

```bash
# 打包产物：指定数据目录
./deen-music-downloader --data-dir /data/deen-music     # Linux
deen-music-downloader.exe --data-dir D:\deen-data       # Windows

# 环境变量方式（适合 systemd / Docker 等不便改命令行的场景）
APP_DATA_DIR=/data/deen-music ./deen-music-downloader
```

## 访问控制与安全

v0.9.0.0 起移除登录体系：单用户自用工具，打开即用，无账号密码（存量数据库中的 users 表保留不动）。

**没有登录意味着：能连上 Web 端口的任何人都能操作本服务**，包括导出全部账号的平台
Cookie、把自定义 API 地址改到自己的服务器（之后全部账号 Cookie 会发往该地址）、删除
下载目录内的文件。请按部署方式确认暴露面：

| 部署方式 | 默认暴露面 | 建议 |
|----------|-----------|------|
| Windows / Linux 本地运行（新装） | 仅本机（`127.0.0.1:45600`） | 无需处理；要让局域网其他设备访问时，把 `web_port` 改为 `*:45600` **并设置访问令牌** |
| 从 v0.9.0.0 之前升级的本地安装 | **所有网卡**（库里保存的旧默认 `*:45600` 不会被自动改动） | 只在本机用：把 `web_port` 改为 `127.0.0.1:45600` 后重启；需要局域网访问：设置访问令牌。启动日志会对"监听所有网卡且无令牌"给出警告 |
| Docker | 宿主机网络的所有人（容器内必须监听 `0.0.0.0`） | 设置 `ACCESS_TOKEN` 环境变量，或把端口映射改为 `127.0.0.1:45600:45600`，见 [README.Docker.md](README.Docker.md) |
| 飞牛 fnOS（统一网关） | 仅 NAS 网关（Unix Socket，不监听 TCP 端口） | 无需处理，由 fnOS 网关自身的登录鉴权保护 |

**访问令牌（可选，默认关闭）**

- 设置方式：环境变量 `ACCESS_TOKEN`（优先，适合 Docker / systemd），或在本机打开
  「设置 → 常规 → 访问令牌」（至少 8 个字符）
- 启用后，除静态资源与 `/healthz` 外的所有页面和 `/api/*` 都需要令牌：浏览器首次访问
  `http://<地址>:45600/?token=<令牌>`，服务会写入 HttpOnly cookie 并跳转去掉地址栏里的
  令牌，之后自动携带；脚本可用 `X-Access-Token: <令牌>` 请求头
- 在设置页启用令牌时，当前浏览器会同时记住新令牌，不会把自己挡在外面
- 令牌对本机访问同样生效（同机反向代理转发的请求也来自 127.0.0.1）
- 飞牛网关模式下跳过令牌校验

**敏感操作仅限可信来源**：无论是否启用令牌，下列操作只对 本机访问（`127.0.0.1`/`::1`，
且 Host 为 `localhost`/回环地址）、飞牛网关、或持有有效令牌的请求开放，其余来源返回 403：

- 导出账号（`GET /api/accounts/export`，含全部平台 Cookie）
- 修改自定义 API 地址及其开关（`custom_api_url`、`qq_api_base_url`、`kugou_api_base_url`、`use_custom_*`）
- 修改下载目录 `output_dir`、监听地址 `web_port`
- 设置/关闭访问令牌（`PUT /api/settings/access-token`）

未启用令牌时，其余功能（含音乐库里的改动和删除）对能访问端口的所有人开放。

## 常见问题

### Q: 添加账号时提示"Cookie 必须包含 MUSIC_U"？
A: 从浏览器登录网易云后，打开 F12 → Network → 任意请求 → Request Headers → 复制完整 Cookie 字符串，其中必须包含 `MUSIC_U=xxx` 字段。也可以直接用扫码登录，不用自己复制 Cookie。各平台 Cookie 获取图文见 [初次使用教程](docs/初次使用教程.md)。

### Q: 下载失败提示"无版权或需 VIP"？
A: 该歌曲需要会员权限，请确保有可用的 VIP 账号。接力模式下会自动切换到 VIP 账号重试。

### Q: 下载失败提示"试听片段"？
A: 当前账号无该歌曲完整版权，只能拿到试听片段（已自动跳过不下载残缺文件）。接力模式会自动换更高权益账号；均不可用则标记失败。

### Q: 同步后歌单里有个别歌显示失败，提示"上游返回值为空"？
A: 上游对已下架 / 失效曲目会返回空曲名。0.7.0 起程序不再用「未知歌曲」兜底（原先会下载成 `未知歌手 - 未知歌曲.mp3`），而是记一条明确的失败记录。判定以**单曲详情的曲名**为准：歌单层名为空但详情名正常时仍正常下载；QQ / 酷狗无单曲详情接口，以任务记录名为准。恢复需在「下载」页的「下载记录」里手动重试——自动 / 定时同步不会重试同一歌单内已失败的终态记录。

### Q: 没下载新文件，记录却显示"已下载"？
A: 这类记录是被跳过的：文件已经存在，或新下载的文件和库里已有的文件声音完全相同（`download_md5_dedup`），程序撤回了重复的那份，沿用已有文件。电脑上鼠标停在状态标签上可以看到具体原因。

### Q: 所有账号都提示"小时限额已满"？
A: 所有启用账号在当前自然小时内的成功下载数已达 `hourly_limit_per_account` 上限，系统会自动暂停 30 分钟后继续，无需手动干预。

### Q: 额度（quota_limit / hourly_limit_per_account）是怎么统计的？
A: 按**全部成功下载**计数（含免费歌曲，0.7.2 起口径明确），不是"可下载的收费歌数量"。这是刻意设计——额度用于控制对上游的请求频率、降低账号风控风险；免费歌同样产生真实请求，也需计入。

### Q: QQ 音乐歌词无法下载？
A: 0.6.0 起新版 QQ 音乐 API 已支持歌词下载；若个别歌曲仍缺失，多为瞬时接口失败，程序会自动重试一次，仍失败则跳过歌词继续下载音频与封面。

### Q: QQ 账号过一两天就失效？
A: QQ 网页 Cookie 名义有效期 60 天，但长期不刷新约 1 天就会失效。程序默认每 6 小时自动刷新一次（`qq_keepalive_hours`），请保持程序常驻运行；已经失效的账号需要重新扫码登录。

### Q: 酷狗匿名下载只能 128kbps？
A: 酷狗音乐 API 对匿名（无登录 Cookie）请求强制封顶 128kbps MP3。如需 320/FLAC/Hi-Res 音质，请在「设置 → 账号」添加酷狗账号（支持扫码登录）。

### Q: 酷狗账号显示"酷狗未提供"到期时间 / 歌词无翻译？
A: 均为酷狗 API 上游限制——`/user/detail` 未返回到期时间字段，翻译歌词（tlyric）接口固定为空，不影响下载功能。

### Q: 修改 Web 监听地址后无法访问？
A: `web_port` 修改后需重启服务才生效（fnOS 在应用中心重启本应用；其余通过启动脚本或手动重启 `python webapp/app.py`）。

### Q: 路径过长导致下载失败？
A: 系统对路径长度有保护机制：非法字符自动清洗为 `_`、超过 240 字符自动截断文件名。若仍失败（如目录部分本身过长），请缩短 `output_dir` 路径。

### Q: 如何暂停或删除某个下载任务？
A: 在「下载」页的「正在进行」里，每个任务右侧有暂停 / 继续和删除按钮，上方另有「暂停全部 / 继续全部」。暂停会保留已下载的临时文件，点继续后从断点续传；删除会立即停止传输并清理临时文件（注意：这里删的是「任务」，「下载记录」里的记录需另行删除）。

## 打包与开发

跨平台一键打包为单文件可执行程序（onefile 模式，依赖全部内置）：

```bash
# Windows
build_win.bat

# Linux（POSIX sh）
chmod +x build_linux.sh && ./build_linux.sh
```

- 产物位于 `dist/deen-music-downloader/`，自动复制 `api/` 三平台二进制并创建 `downloads/` 占位目录
- PyInstaller 不支持交叉编译，各平台产物须在对应平台构建
- 推送 `v*` 标签时 GitHub Actions 先跑测试，再自动构建 Windows / Linux zip 与 fnOS `.fpk` 三份产物并发布 Release
- 跑测试：`pip install -r requirements-dev.txt` 后执行 `python -m pytest -q`

更多开发细节（技术栈、目录结构、核心机制、数据模型、API 接口、运行模式）见 [docs/技术文档.md](docs/技术文档.md)。
