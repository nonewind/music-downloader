# Deen音乐下载器-初次使用教程

## 一、打开即用

v0.9.0.0 起移除登录体系：浏览器打开应用地址即可直接使用（单用户自用工具）。
fnOS 由系统自己的登录保护；其他部署方式如需让局域网设备访问，请在「设置 → 常规」
设置访问令牌，详见 README 的「访问控制与安全」。

界面共 4 个页面：**找歌**（首页）、**下载**、**整理**、**设置**。电脑上导航在顶部，手机上在底部。

### 2、服务设置

1. 「设置」页的「常规」和「API 服务」保持默认即可（已内置 API 服务，无需用户外部搭建）

2. 「设置 → 下载行为」说明如下：
    ![](pics/2026-09-08-23-24-54-image.png)

3. 「设置 → 自动同步」：
      ![](pics/2026-09-08-23-25-54-image.png)

4. 登录账号，目前支持 QQ、网易云、酷狗音乐。打开「设置 → 账号」，点右上角「添加账号」，可以直接扫码登录，也可以粘贴 Cookie
   ![](pics/111.png)

5. 添加歌单：在「找歌」页的「我的歌单」点「用链接添加」，粘贴歌单链接或 ID（歌单添加后会根据你设置的同步时间自动同步，也可以点「立即同步」）：
   
   - 网易云音乐，= 后边`2179431622`是歌单id。
     https://music.163.com/#/playlist?id=2179431622
   - QQ音乐，最后的数字`7074538435`是歌单ID
     https://y.qq.com/n/ryqq_v2/playlist/7074538435

## 三、找歌下载

在「找歌」页搜索歌曲或专辑，点每行右侧的下载。进度在这一行和页面底部的下载条上都能看到；失败的歌到「下载」页的「下载记录」里看原因、重试。

## 附：各平台 Cookie 的获取

扫码登录不需要 Cookie。只有想手动粘贴 Cookie 时才看这一节。


- 网易云打开网址：https://music.163.com/

![](pics/2026-09-08-23-39-17-image.png)

- QQ音乐打开网址：https://y.qq.com/n/ryqq_v2/profile/like/song

![](pics/2026-09-08-23-43-03-image.png)

- 酷狗音乐直接扫码获取cookie即可
