Web 服务
格式: host:port，如 127.0.0.1:45600（仅本机）或 *:45600（所有网卡）；修改后需重启服务生效。本服务没有登录，监听所有网卡时同一网络内任何人都能操作，请同时设置下方访问令牌
启用后其他设备需先访问 http://地址:端口/?token=令牌 一次（浏览器记住后免输）；导出账号、修改自定义 API 地址/下载目录/监听地址仅允许本机或持有令牌的访问
